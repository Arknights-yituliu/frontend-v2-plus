统一资源入口：[src/utils/arknightsResource.js](../src/utils/arknightsResource.js)

- `OPERATOR_AVATAR_BASE_URL` = `https://cos.yituliu.cn/arknights/resources/avatar/`
- `OPERATOR_SKILL_ICON_BASE_URL` = `https://cos.yituliu.cn/arknights/resources/skills/`
- `OPERATOR_EQUIP_ICON_BASE_URL` = `https://cos.yituliu.cn/arknights/equip-icon/`

- `getSkillIconUrl(iconId)` → `{skillsBase}skill_icon_{iconId}.png`（内部会把 `x5b` / `x5d` 还原为 `[` / `]`）
- `getEquipIconUrl(icon)` → `{equipBase}{icon}.png`

## 备注

1. 模组图标组件 `EquipIcon.vue` 已删除，页面统一使用 `getEquipIconUrl` + `<img>`；尺寸、手机端尺寸与 `drop-shadow` 已迁到各页面 CSS。
2. 技能图标 id 中的方括号在数据里是 `x5b` / `x5d` 转义形式，资源文件名使用原始方括号，`getSkillIconUrl` 已处理。
3. 组件内部会按窗口宽度切换桌面 / 手机尺寸，替换为 `img` 时需用媒体查询补齐手机尺寸。
4. 仍有页面自行拼接模组地址：[rankBarContent.vue](../src/pages/material/elite/components/rankBarContent.vue)、[detailDialog.vue](../src/pages/material/elite/components/detailDialog.vue)（本地 `getEquipIcon` 函数，带无模组图兜底），可后续统一改用 `getEquipIconUrl`。
5. 技能图标组件 `SkillIcon.vue` 已删除；原组件默认会把尺寸内缩（桌面 -4px、手机 -2px），当前 CSS 按此还原，带 `border` 的调用额外补了 2px 蓝色边框。
